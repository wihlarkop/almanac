# BE-16 — Model creator eligibility audit

**Method and limits.** Audited all 62 provider IDs in `providers/*.yaml`. `VERIFIED_FIRST_PARTY` requires a direct first-party source that names the cited model family; general homepages or API entry points do not meet that threshold. `MIXED_FIRST_PARTY_AND_HOST` is limited to provider-authored families named in the linked official sources and does not imply that other hosted catalog entries are owned. `AMBIGUOUS_REVIEW` records a missing family-level source; it is not a finding that the organization did not create the model. Catalog filename stems are examples only, not proof of exact version lineage. No model YAML, provider ID, alias, API contract, or migration is changed. Last reviewed: 2026-11-18; this date is the audit date, not a source freshness guarantee.
